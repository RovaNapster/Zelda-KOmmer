**Author:** Rovanapster (Rova awfully SIRI)

## 📖 Översikt
Detta repository utgör kärnan i **CREED Wealth Management System**. Det är en autonom förmögenhetsmotor designad för att eliminera subjektivitet vid värdering av fysiska tillgångar (klockor/guld) och historisk likviditet.

Genom att kombinera formell logik, realtidsdata från marknaden (Creedy Cash-Motor) och en STIL-brygga (12% premium på verifierad proveniens), levererar systemet en total och matematisk "Net Worth"-validering dagligen.

---

## 🏗️ Systemets Komponenter

### 1. Formell Logik (Isabelle/HOL)
All tillgångsvalidering (klockor, investeringsguld, historisk kassa) bygger på matematiska bevis för att undvika "Errors".
- `CreedValuation.thy`: Regler för klockornas proveniens och STIL-klassning.
- `CreedLiquidity.thy`: Verifierar kassaflödet från 2008 till 2026.
- `CreedCommodity.thy`: Säkerställer guldets renhet (24k/0.999).

### 2. Creedy Cash-Motor (Python)
Ett autonomt skript (`creed_wealth_engine.py`) som körs dagligen via GitHub Actions.
- Hämtar spot-priset för Guld (USD/oz) och USD/SEK via `yfinance`.
- Adderar historiskt verifierad likviditet (baserat på 54 datapunkter, 2008-2026).
- Beräknar total förmögenhet och exporterar resultatet till `creed_data.json`.

### 3. Frontend: AMOLED PWA (OnePlus 15 Optimized)
En djupblå "Dark Mode" webbapplikation byggd för OnePlus 15:s 165Hz-skärm.
- GPU-accelererade CSS-animationer (`translateZ(0)`).
- `requestAnimationFrame` för laggfri uppräkning av siffror.
- **Live URL:** [https://rovanapster.github.io/rowan-python/](https://rovanapster.github.io/rowan-python/)

## ⚙️ CI/CD Pipeline (GitHub Actions)
Motorn körs automatiskt varje vardagsmorgon kl 06:00 CET via `.github/workflows/creed_pipeline.yml`. 
Den hämtar nattens stängningskurser, kör Isabelle-verifieringen och uppdaterar PWA:n med färsk data.
